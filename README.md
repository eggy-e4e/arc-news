# Arc iOS Shortcut Setup

Arc is a mobile HTML app designed to be opened by an Apple Shortcut after the Shortcut gathers RSS stories and asks Apple Intelligence to produce `arc.edition.json`.

## Files

- `index.html` is the app.
- `arc.config.json` contains RSS sources, category settings, and the Apple Intelligence prompt.
- `arc.edition.json` is generated by the Shortcut at run time. It is not required to exist for the app to open.

## Recommended Shortcut Flow

Use this when `index.html` is hosted somewhere reachable by the iPhone.

1. Get `arc.config.json`.
2. For each enabled category, fetch the RSS URLs in `sources`.
3. Keep recent items using `lookback_hours`, `maximum_items_per_feed`, and `maximum_stories_per_category`.
4. Combine the selected RSS item titles, publishers, dates, URLs, and summaries into text.
5. Send that text to Apple Intelligence using `apple_intelligence_prompt`.
6. Confirm the result is valid JSON text.
7. URL-encode the JSON text.
8. Open:

```text
https://YOUR_ARC_HOST/index.html?edition=URL_ENCODED_JSON
```

Arc will render the query edition before trying `arc.edition.json` or fallback data.

## Large Edition Flow

Use this if the encoded URL gets too long.

1. Put `index.html` in iCloud Drive, for example:

```text
iCloud Drive/Shortcuts/Arc/index.html
```

2. In the Shortcut, generate the edition JSON with Apple Intelligence.
3. Replace `<` in the JSON with `\u003c`.
4. Get the contents of `index.html` as text.
5. Replace the first `<script>` with:

```html
<script id="arc-edition-data" type="application/json">
PASTE_OR_INSERT_EDITION_JSON_HERE
</script>
<script>
```

6. Save the result as:

```text
iCloud Drive/Shortcuts/Arc/Arc Today.html
```

7. Open `Arc Today.html`.

Arc reads the inline JSON before trying the query parameter, `arc.edition.json`, or fallback data.

## Shortcut Output Contract

Apple Intelligence must return JSON only:

```json
{
  "generated_at": "2026-07-12T07:30:00+07:00",
  "locale": "en-US",
  "categories": [
    {
      "name": "World",
      "stories": [
        {
          "id": "world-example-story",
          "headline": "Headline shown in Arc",
          "summary": "One concise sentence for the carousel.",
          "briefing": "Two to three factual sentences for the reader.",
          "publisher": "Publisher",
          "published_at": "2026-07-12T06:30:00+07:00",
          "reading_minutes": 2,
          "url": "https://example.com/story",
          "image_url": null,
          "image_alt": null,
          "topics": ["Topic"],
          "developing": false,
          "sources": [
            { "publisher": "Publisher", "url": "https://example.com/story" }
          ]
        }
      ]
    }
  ]
}
```

## Arc Data Priority

Arc loads data in this order:

1. `window.Arc.loadEdition(editionObject)`
2. Inline `<script id="arc-edition-data" type="application/json">`
3. `?edition=URL_ENCODED_JSON`
4. `./arc.edition.json`
5. Embedded fallback edition

For a normal iOS Shortcut, use option 3. For long editions, use option 2.
